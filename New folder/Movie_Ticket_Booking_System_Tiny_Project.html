Introduction

This tiny project analyzes a Movie Ticket Booking System database using R. The database contains customer, movie, theatre, show, seat, payment and booking information.

The analysis follows the basic R Markdown approach used in the reference project: importing a CSV file, displaying the data, checking its structure and missing values, performing summary statistics, creating frequency tables and visualizations, and studying relationships between numeric variables.

Keep this R Markdown file and the CSV database in the same folder.
